# Security policy

## Supported versions

Only the latest `main` branch receives fixes.

## Reporting a vulnerability

If you find a security vulnerability, please report it privately:

- open a GitHub security advisory on this repository
  (Security tab -> Report a vulnerability), or
- contact the owner via their GitHub profile: [@pennico](https://github.com/pennico)

Please do not open a public issue for security problems. Include a
description, reproduction steps, and impact if possible. You will get
an acknowledgement; fixes are released as soon as practical.

## Scope notes

This project is a self-hosted application: it runs on your own server,
holds no user accounts beyond your own, and stores API keys only in a
local `.env` file that is never committed. Never paste API keys into
issues or code.
